# Curunír public-source intelligence and kernel-admission shadow V4

This package is a research-shadow implementation. It does not establish intelligence accuracy,
production authentication, canonical admission, or autonomous decision authority.

The executable flow is:

1. `preregister` freezes the question, scope, languages, budgets, stop rules, and query plan.
2. `live-capture` persists query lineage and non-evidentiary search leads, records an access decision,
   writes retrieval-start metadata, captures immutable bytes, writes the final retrieval record, and
   only then normalizes supported content.
3. `retry` can repeat a preserved technical failure within the acquisition budget. It cannot change
   the prior access decision or bypass a credential, WAF, rate limit, or legal restriction.
4. `assemble` compares deterministic, repository, and AI-assisted candidate providers; resolves
   reversible identities and directional source origin; builds claims, evidence bases, contradictions,
   hypotheses, sentence evidence, mission handoffs, and review-blocked kernel proposals.
5. `replay` uses captured bytes and persisted provider records only. It performs no discovery,
   network retrieval, or provider invocation.
6. `review-init`, `review-send`, and `review-receive` exchange serialized, access-filtered packets
   between independently persisted strategic-evidence and kernel-review nodes. The review node cannot
   browse, acquire, approve human review, or write to the kernel.
7. `stress`, `mutate`, and `security` execute the bounded scale, mutation, and threat-model gates.

All report facts require a mapped extraction candidate, claim, evidence basis, and captured source.
Translations and derivative publications remain dependent sources. Retractions remove active support
without deleting history. Search snippets and failed acquisitions can never support report statements.

Kernel inspection is AST/schema read-only. Dry runs produce `WOULD_*` operations in a separate shadow
namespace. V4 never imports `argus.actions`, opens PostgreSQL, executes SQL, mutates protected files, or
crosses the genuine-human-review gate.
